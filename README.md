# matias-holdingpage-02

Holding page for matiasjansen.com, built with React, TypeScript, and Vite. Uses `three`/`rapier2d` for the canvas animation (`src/MurmurCanvas.tsx`, `src/PhysicsCanvas.tsx`) and custom typography handling (`src/typography.ts`, `src/typographyTokens.ts`).

## Fonts

This repo includes licensed/trial font files (Suisse Int'l, Suisse BP Int'l, Untitled Sans). These are not open source — do not redistribute them or publish this repo publicly with the fonts included.

## Run

```sh
npm install
npm run dev      # start the dev server
npm run build    # type-check and build for production
npm run lint     # run eslint
```
